# Art notes / 独立测试记录

## 目标与参考

研究 Control 的日常官僚空间：高大板模混凝土、暗绿/灰金属档案家具、暖黄标识、荧光灯工作池，以及门内红色异常光。主要活动是访客排队、案卷核验、档案入库。用一处检查桌、一组档案柜和一个真实可见门槛/内转弯通道构成小切片。

参考图实际逐张查看过。`control-3` 是黄色 SHELTER 入口与办公门厅，`control-4` 是高档案柜、红光和悬挂荧光灯；准确 Steam 图片 URL 见 manifest。没有复刻战斗人物与特效。

## 第一轮

Godot Metal Forward+ 实际输出三机位，并保留 PNG 及 native 场景快照。自查和 root 逐图评审发现：

- Concrete Panels 的密集肋板贴图选型错误，墙梁顶地同材质重复，读成瓦楞装饰板；整体明显有旧 FPS 感。
- 档案柜朝向错误，柜背面完全不能承担档案场所叙事。
- 环境过暗，地面与柜细节丢失；SHELTER 被吊灯遮挡。
- 右侧边界漏背景；门后平墙缺乏转折深度。
- 桌面虽有纸张、托盘与灯，仍需要现成小道具。

## 第二轮

保持三个固定相机的位置与 FOV，不扩展玩法。

- 新检索并实际查看/下载 Concrete Wall 009 与 Concrete Floor Worn 001；墙面大尺度、弱 normal、最终固定高粗糙度，地面独立纹理。
- 旋转档案柜，增加局部补光，让抽屉、把手和标签框可读。
- 下载并布置真实 binder notebook（开/合两本成对放在工作台）、cardboard box、vintage radio transceiver；保留现成桌椅和灯原始PBR。
- 门后有地面、顶、侧壁、后壁与右转深度；最后补闭右侧后墙缺口，降低意外空洞。
- 移动挡字荧光灯、提高地面可读性、启用4x MSAA；摄像机仍不变。

root 评价：主要反馈有改善，混凝土大板尺度正确，柜面可读、工作组更完整，灯牌不冲突，转折通道可辨。随后要求冻结；冻结不代表用户美术验收。

## 明确未解决的质量上限

- 空间陈设仍偏稀，左侧大墙和前景缺少自然生活层次。
- 纸箱排列过整齐；档案柜为低细节旧资产，和高细节 PBR 桌椅存在保真度差异。
- 墙面统一纹理重复明显；粗糙度已提高，但仍缺少不同构件的表面处理差异与局部接触污迹。
- 简化托盘/栏杆/纸张与扫描型真实模型之间仍有风格与细节差异；不是 Control 的资产与灯光层次。
- 建筑结构主要为自制壳体，没有成功找到并交付合适的现成混凝土建筑套件。这是素材检索能力的实际缺口。
- 三固定视角可审阅；不包含完整可玩关卡或完整封闭的游戏空间。
