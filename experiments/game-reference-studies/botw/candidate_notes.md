# Independent candidate screening — 2026-11-13

The study began in an empty directory. Only raw assets and licenses from the authorized cache were read; no old scene or generator was used.

| [ambientCG Rock030](https://ambientcg.com/a/Rock030) and [Ground037](https://ambientcg.com/a/Ground037) | 1K JPG PBR archives actually downloaded; CC0 including redistribution. Reference interpretation: sunlit, pale gray stone, readable aperture, saturated but subordinate green grass; storm image used only for edge growth and scattered rubble placement. Reference images are not texture inputs. The result remains a generic stylized wayside ruin, with a narrower motif/ornament vocabulary than the game reference.
