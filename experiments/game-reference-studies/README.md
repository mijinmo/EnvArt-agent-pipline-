# 游戏截图参考测试 · 2026-11-13

独立 agent 从空 Godot 项目开始，使用 `godot-envart` skill，以实际游戏画面作视觉参考。测试对象是环境美术，范围是一个可近看的局部；不开发玩法、控制器或功能测试套件。

| 案例 / 项目入口 | 小样方向 | 主要视觉挑战 |
| --- | --- | --- |
| [旷野之息](botw/project.godot) | 自然侵入的石砌遗迹入口 | 草石过渡、柔和材质、自然分布与比例 |
| [Control](control/project.godot) | 混凝土办公检查站 | 大形体、现实办公道具、灯光与材质一致性 |

| [Firewatch](firewatch/project.godot) | 林间设施 | 植物轮廓、色块、地形和空气透视 |

## 测试方式

每个 agent 只接收 skill、实际截图、独立目录和原始素材缓存权限；不接收之前的场景或生成器。独立检索素材，保留真实候选与取舍、下载文件及许可证。原游戏截图只作视觉研究，来源见 `references.json`，不作为模型或纹理使用。

首轮独立完成；修订轮接受主 agent 的具体画面反馈，因此两者分别反映独立产出能力与接受美术指导后的修正能力。

每组保留两个阶段：首轮实际 Godot 渲染 → 主 agent 看图指出主要差距 → 同机位修订。至少保留总览、细节、地面/空间过渡三个视角。必要技术检查仅覆盖导入、载入与真实出图。

## 三项能力分别判断

- **找素材**：是否找到可实际取得、许可可用且适合目标的建筑/props/自然素材；候选选择有没有美术理由，实际画面是否兑现。仅复用原有缓存不能充分证明新检索能力。
- **细节填充**：是否形成有用途、有支撑关系的道具组；边缘、地面和接缝是否完成；密度、疏密和重复是否自然。道具数量不作为分数。
- **美术风格统一**：轮廓比例、表面细节、色彩、光照是否协调，同时是否接近指定参考。自身统一但偏离参考，也要明确扣分。

评价使用 1–5 的观察性等级：1 未体现；2 有局部表现但主要问题明显；3 小样可读、仍有明显缺口；4 多视角表现稳定、仅局部不足；5 在本次小样范围有充分画面证据。分数是人工看图判断，不是客观性能指标，也不代表用户已验收。来源难度不同，四组和一至两次反馈修订不足以证明泛化能力。

结果已整理到 [HTML 图文报告](../../docs/game-reference-studies.html)，包含原作截图、同机位前后图和三项能力的证据。全部结果都未达到参考游戏的美术完成度。原始评价数据见 `review.json`，反馈过程见 `review-log.md`。

## 打开工程

每个链接都是独立 Godot 4.7.2 工程。导入其 `project.godot`、等待资源导入后按 F5，默认是静态总览。其他机位在场景树的 Camera3D 中通过 Preview / Current 查看；没有新增玩家控制器或玩法。各项目 README 提供可选出图方式。

Control、Dishonored、Firewatch 保留两轮图；旷野之息最终是 `round-03`。它的 `round-02` 是根据中间参数重渲染的版本，已明确标注，HTML 主对照使用原始第一轮与冻结第三轮。`build.gd` 只用于可选重建，会覆盖手工编辑的主场景，不需要先运行它。

图文报告使用本地图片，可离线打开；保留仓库内 `docs/` 与 `experiments/` 的相对位置。原游戏图片仅作为本次分析参考，版权归原权利人。
