# Control 档案交接区盲评

**综合排序为 D、B、A、C。** D 与 B 接近。D 在门外就能辨认部门，进到桌边又能辨认取档、签收和等候的位置，三个机位连起来最像同一处正在使用的设施。B 对分拣工作的表达更清楚，单看桌边近景我会选 B。A 和 C 的工作区也成立，两者的差距主要出在搬运道具的摆法和入口收边。

主参考能辨认冷灰混凝土墙、薄金属货架、带提手的牛皮纸档案盒，以及有人使用的桌椅和小电器。人物挡住部分地面，露出的区域支持细颗粒、低对比接缝和柔和反光。辅助参考给出了木饰面、红地面和部门目录的搭配。起始图已经有工作台、收音设备、台灯、档案柜及后墙目录，比较重点是各版怎样把这些条件连成一个局部。

| 候选 | 与参考的贴合 | 局部内部的统一与不足 |
| --- | --- | --- |
| **D** | 整体图左侧蓝灰钢架、带提手的档案盒和取物梯，右侧白桌与靠墙等候椅，最接近主参考里储存区紧邻办公区的关系。门口红地面收到门洞，木饰面包住深色门框，门楣、侧边面板和远处目录在三个距离上都能辨认用途。 | 半开的柜屉朝向工作位，桌边的杯子、纸盘和单据把动作落到了桌面。近景也暴露了材质差距，架上盒子棱角齐整、色面很平，紧邻的落地纸箱却有细密折痕，右侧黑椅的大片亮斑也抢过了签收台。 |
| **B** | 整体图中连续的混凝土墙、低对比地缝和冷灰底色给纸箱与台面让出了轮廓。辅助参考的木墙分缝和目录箭头在门口得到呼应，红色地面两端露出硬直边界，较像单铺的一块。 | 左墙的收件、复核、结案分区能直接对应架上物件。近景里打开的档案盒、桌边抽出的纸托、待办夹和灯下单据说明了文件如何流转，桌面仍留有操作空间。架上新盒和捆带旧箱的精细度有落差，三列货架与等高标牌也略显陈列化。 |
| **A** | 冷灰墙的拼缝、孔点在整体图中可读，木饰门侧和红地面呼应辅助参考。地坪在整体图下沿出现醒目的圆形白亮斑，近景左下又有暖色亮斑，反光比参考中露出的地坪突出。 | 近景最有说服力的是装着旧纸箱的手推车停在桌边，纸盘、单据与搬运位置紧邻。架上多层旧箱的折损位置和朝向相似。门外同一眼可见门楣、左牌、右牌三处“04”，侧牌彼此争夺注意。 |
| **C** | 近景的混凝土有清楚的云斑与板缝，墙角和吊顶仍能读成连续的浇筑面。整体图中椅子、车和箱子的落地阴影清楚；暖木护墙与绿牌也能把目光引到办公桌。 | 架前空手推车与架柱正面重叠，待运箱仍在桌旁地上，两处之间的交接关系比 A 松散。近景一排箱子反复出现相似的白标签与捆带。门口两侧木板较暗，红色地面从门后起，矩形角从门侧露出，作为路径的连续性最弱。 |

四组画面在指定距离都能辨认墙体的材料与尺度；最显眼的重复来自成排箱体。B 的台面和地坪光照较克制，D 的优势集中在档案架、工作位和入口的整体对应。静态图可以比较这些机位的受光和阴影，移动时的反光变化与其他角度的遮挡仍未验证。
