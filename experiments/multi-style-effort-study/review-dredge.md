# DREDGE 港边检修棚视觉盲评

**综合首选 D，B 与 A 并列第二，C 略后。** D 的优势在于从院门看进去，能一路找到船、工作台和正在使用的器具，三个距离都讲得通。B 与 A 的差距随机位反转，B 的港村关系和近景标识更清楚，A 从暗门望向灯下工作区的暮色更好。只看近景仍选 D，B 居次。

主参考里，暮色把茅顶压成深色的大轮廓，浅墙、细长木桩和错落的连桥把房屋连成港村，船舱的暖光只占很小一块。灯塔图补充了低太阳、冷色海面和成片断开的反光。近景道具按功能能否看懂、与相邻表面是否合拍来判断。起始图已有吊臂、门架、海图、浮标和工作台，四案的差异主要在这些物件之间的关系。

| 候选 | 总览与参考贴合 | 近景、门洞与内部统一 |
|---|---|---|
| A | 深紫的碎片状屋檐和橙天先交代了傍晚，青布棚也使人一眼找到工作区。但棚面比周围屋顶更亮、更完整，远海又铺了一层细密银点，抢走了近岸建筑的注意力。 | 暗门内正好框住受灯光照亮的海图，暖光从门内引向右侧棚柱，四案中进门的光线引导最好。走近后，灯斑盖住一块图面，桌、桶、凳密布的木纹与左前大块平涂的磨轮支架精度相差明显。 |
| B | 海面左右的架空小屋直接呼应主参考，尖碎檐口也保留了茅顶的剪影感。但两座并排的小屋近乎复制，远屋与院落间欠缺连桥或岸线这样的视觉联系。 | 蓝绿门牌、棚牌和纸质航图有共同的字样、边框和色调；灯旁的浮标与桌右待用的浮标能读成同一项工作。门洞正对航图，但浅色地板、受光白墙和泛白的浮标亮度接近，跨过门槛后，棚下应有的阴影深度很弱。 |
| C | 暖天、暗红屋顶和冷海分层清楚，左墙的吊笼及其投影让吊臂一侧有了用途。成排圆边瓦片过于齐整，远岛和树尖像一排几何块，削弱了参考里沿海聚落的自然起伏。 | 桌上铜色潜水盔轮廓利落，与背后的表盘形成明确焦点；桌板、墙面和前景磨轮的简化程度相近。门洞里最醒目的仍是起始图已有的海图和磨轮，潜水盔藏在门柱后。右侧大箱虽添编号和压条，在这个机位仍是一整块平面，近景的亮点没能带动过渡。 |
| D | 深红屋面、浅山墙和冷青阴影先立住建筑体块，再由左侧船身的红边接到右窗和棚牌。低太阳与冷海贴合辅助参考；远处等距尖树和偏平的海面仍比参考生硬。 | 从门洞可见后墙海图，旁边架起的小船交代了院子的用途。到工作台前能沿卷轮看见搭过桌沿的测深线和垂锤，再对上海图，检修内容最具体。门、箱、窗的漆木处理也相互呼应。近景墙斑在亮墙与暗墙上都很重，上方鱼牌又占去不小画幅，两处都会和器具争视线。 |

**参考贴合与内部统一各有侧重。** 对照港村图，B 在水上建筑形制上最直观，D 在同一画面组织深屋顶、浅墙和港作空间上更成熟，A 则最能保住暮色中的局部灯光。看整套资产，D 从船到工位的尺度、色面和用途衔接最好，B 的标识与建筑次之。C 的简洁在潜水盔近景成立，A 的灯光在门洞成立，两者的长处都随机位变化更大。
