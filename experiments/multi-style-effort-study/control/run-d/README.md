# Control · 档案交接室

第一轮可在 Godot 4.7.2 打开 [pass01.tscn](pass01.tscn)，按 F6 查看。三个固定机位的实机图分别为 [全景](evidence/pass01_overall.png)、[工作台](evidence/pass01_detail.png)、[入口](evidence/pass01_transition.png)。

主参考右侧的钢架、打孔牛皮纸箱和归档标签构成连续的储存面，前桌有收音设备和纸堆，地坪比混凝土墙面更暗、颗粒更细。辅助图中木饰面、浅色金属边框、目录和红色地面共同识别出部门入口。起点中这两类空间都有基础道具，货架之间的密度、手边物件状态和门框材料处理是这次续作的重点。

第一轮使用既有扫描货架和扫描纸箱贴图，制作冷蓝漆货架、开孔档案箱、闭盖箱、分隔签、双层金属收件盘和咖啡杯。沿用原办公桌、收音机、装订本、推车、灯及柜体，为抽屉加面板和索引卡。重制门口对讲面板、门楣、木饰面分片、工作海报和接收表格。保留天窗，使用世界坐标的扫描混凝土和水磨石、胡桃色薄木饰面及入口绒面处理材质。

看过首轮三图，连续钢架和多层夹件补齐了交接活动。抓孔后方的纸夹和局部高光太亮，纸板的大斜纹容易认出重复。近景的柜体漆拼色和两张同款休闲椅削弱了器物区分。入口木分片顶端参差，门楣有圆形过曝斑。首轮 Metal 成功出图一次，GPU 等待 0.00 秒。启动前一次文本载入检查发现小数格式错误并已修正。白盒和机位简表与起点逐字节一致。
