## 美术判断与制作记录

主参考右侧的钢架、开抓孔的牛皮纸箱和档案标签构成连续储存面，桌上有收音设备和纸叠。混凝土墙面的大块明暗、地坪细小骨料及阴影中的冷色共同支持这组暖纸箱。辅助图中木饰面、金属边、目录和红色地面识别出部门入口。起点已有扫描家具、天窗和工作灯，档案架稀疏，部分柜面与门侧设备在近景中像单色面板。[储藏室主参考](https://cdn.mos.cms.futurecdn.net/naFRXRm5Rufg52AvrWMD4i.jpg) · [部门入口辅助参考](https://image.jeuxvideo.com/medias-md/156691/1566905271-9637-capture-d-ecran.jpg)

**第一轮。** 保留原桌、收音机、装订本、推车、工作灯和柜体，沿后墙装配三个实物钢架，调整漆色。纸箱原型取自运输箱扫描，但库存用途需要独立折板、真开孔、抽取标签、夹件与闭盖型。桌上双层铁丝盘、签收页、杯和推车连接待收与待发两端。灯罩加格栅，配置蓝紫色天光反弹和局部工作灯。入口增加木分片、拉丝金属门禁面板与导向。交接制度海报、单据和目录均为本次自绘。

看过首轮三图，存储架、文件盘和入口用途已能辨认，但高亮纸夹透过抓孔，成排的斜向纸纹暴露重复。两张同款休闲椅令职员与访客区相似，柜前漆色分块，门楣有圆形过曝斑，局部饰面收头参差。

**第二轮。** 抓孔后增加内折舌，保留真实穿孔，改用扫描纸板的高频纤维和更清楚的套印格；闭盖、开盖及取件空档混排。在实物架后补斜撑，架前放置带止滑踏面、连杆和胶脚的折叠取件梯。原档案柜增加拉开的带吊夹抽屉和侧面清单。访客椅保留扫描坐垫、靠背和弯板，另装弯管底架；调低皮面明度，保留原 UV、法线及粗糙度。推车重调冷蓝漆，仅替换底色，继续使用原法线、金属度、粗糙度与遮蔽。入口改成完整木门套与独立金属灯盒，调整照射方向。

最终三图中，开孔和标签在货架上分离清楚，拉出的抽屉、踏梯和正在分拣的文件可以相互解释。全景的上半幅有较大的灰墙和顶棚留白；近景的柜身侧板仍很平，访客座垫亮面偏强，档案箱的棱角仍比参考整齐。入口的过曝斑已去除，右侧原白盒平台仍占画面一角。此处展示静态机位，没有测试移动时的反射或贴图稳定性。

## 可编辑资源与许可

- 混凝土复用 smooth_concrete_floor 的色、粗糙与 OpenGL 法线，按世界坐标双尺度混采。第一轮板宽 2.46 m、浇筑带高 2.8 m，拼接和孔圈用导数软化。地坪沿用 Terrazzo Tiles，最终 UV 频率 0.405/m，粗糙度基值 0.235。木饰面沿用 Plywood 扫描，分叶改变纹理方向，薄漆层保留法线。参考色彩通过本地照明和独立材质实验近似。现场材质、灯光和节点参数可在场景及 [首轮资源](edition01)、[二轮资源](edition02) 中修改。首轮资源冻结。
- Poly Haven 钢架作者 James Ray Cock。推车作者 Jule Bielitz。座椅作者 Kuutti Siitonen，文件纸堆作者 Ulan Cabanilla。实用扫描模型、各材质及其已交付分辨率以随附清单为准，实际使用的是已提供的完整免费 CC0 本地文件。Ron Kapaun / 3TD Studios 的 OfficeFileCabinet_01 来自 CC0 Office Starter Pack。[原资产和归属](provenance/asset_manifest.json) · [货架与推车清单](provenance/detail_manifest.json) · [地坪、薄木与扫描选择](provenance/astra-v2/selection.md)
- 新制档案箱、纸质分隔、双层盘、杯、折梯、抽屉、钟壳和自绘印刷物用于本样板。原参考图片未作为纹理导入。工程无需联网、运行生成器或烘焙即可打开。

## 验证与耗时

两轮各重新从磁盘载入场景，以统一 Metal Forward+ 捕获 3 × 1600×1000。GPU 锁的排队时间两轮均为 0.00 秒。技术重拍 0 次；首轮在出图前的文本载入检查中修正了一次小数写法。最终 F5 入口载入通过，冻结清单哈希一致。两轮捕获的 17 个 StaticBody3D 和三个相机简表均与起点逐字节一致，门洞原碰撞净空 1.2 × 2.3 m 保留。薄地面饰层、门套和陈设均无新碰撞。图形进程退出时两轮各报告 7 个 Texture RID 清理警告，三图均已正常写入并检查。

墙钟超过 30 分钟软目标。第一轮提交记录为当地时间 18:03，最终出图记录约 19:46；两轮间出现长时间墙钟间隔，GPU 锁未记录等待，无法据此区分其余等待与活跃制作时间。制作止于第二轮，未加第三轮返工。
