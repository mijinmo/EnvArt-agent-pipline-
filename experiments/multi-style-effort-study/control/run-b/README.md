# Control · 档案交接室

使用 Godot 4.7.2、Forward+ 与 Metal。在编辑器打开本目录的 project.godot；pass01.tscn 保存第一轮。三个镜头分别是 Cameras/room（全景）、Cameras/props（桌边）、Cameras/door（通道）。模型与场景都是静态可编辑资产。

## 画面依据与范围

主参考图右上能看见钢架上成列的开口牛皮档案盒，前方有手孔、内容印章，露出的文件量不同。桌上收音机与杯子有明显的使用联系；宽混凝土墙只被小幅印刷品打断，深色地坪含细骨料，桌腿近处能看出反光。辅助图显示连续木饰面、横条目录及偏红的通道地面。转译只涉及档案交接角和门洞内外的近处。原图人物、文字和图像没有作为贴图进入工程。

从三个起点镜头看，原有桌椅、收音机、台灯和手推车的比例适合保留，单列薄架、反复出现的封箱和偏亮的地面削弱了档案活动的可辨识性。门前两侧素混凝土与后方木质目录之间也缺少联系。按墙面进件 → 登记桌 → 上架的使用顺序组织工作面，保留中间通行空间。

## 首轮制作

- 延续 James Ray Cock 的 steel_frame_shelves_01，按 0.11 倍原始资产组成三联架。两个侧架各约 1.21 米宽，真实原架保留层板、立柱与连接件。中架保留原来的有带封箱和账册。两侧新制作有壁厚、贯通手孔、切边和标签夹页的开口匣 A、B，以及配套有盖匣 C。前板油墨以 Rahul Chaudhary 的 cardboard_box_01 彩色扫描中的纸面裁样作底。GLTF、BIN 和外部面印可分别编辑。
- 保留金属桌、推车、台灯、无线电、便笺与笔记本的原资产。抽出金属桌原模型的浅托板，在桌边加入咖啡杯、交接单和待查文件匣。用原有颜色、法线和 ARM 图为 Kuutti Siitonen 的原椅子压低暖棕色，把深蓝黑座面与金属底座分开。
- 墙以 smooth_concrete_floor 的原始扫描为底，用两个方向与频率混合颜色，加入有抗锯齿的 2.45 × 2.72 米支模接缝与浅封孔。墙不跟随网格 UV 复位。地面采用 terrazzo_tiles 彩色、粗糙、法线三张图，骨料与 2.16 米填缝分开，微表面粗糙度为 0.235 加原粗糙度通道 × 0.22。入口段另有低反光酒红表面。
- 木作基于 Rob Tuytel 的 plywood，竖向切片、偏红木色，并在相邻薄板间错开纹理。门侧加薄饰面、门外金属收口、踢脚和读卡槽。东墙有圆形石英钟、原创新档案归位宣传画；北墙高处是两段百叶回风口。所有图形与表格在本轮绘制，圆钟、纸盒和管片均有实体厚度。
- 漫射主光来自既有天窗，文件桌与门后目录保留局部灯。减弱原吊灯打在上方墙面的硬阴影，调节室内冷色环境光，加入屏幕空间反射。灯光与材质同时改变，固定画面反映组合结果。

## 素材范围

主要建筑表面、桌椅、架、车、纸箱、台灯、收音机与文具为本工程冻结的 Poly Haven 完整免费 CC0 素材，沿用本地实际具备的 1K 模型贴图、1K 木材与水磨石、2K 混凝土。档案柜来自 Ron Kapaun / 3TD Studios 的完整免费 Office Starter Pack，仅使用该包的文件柜。每项原始文件、作者及许可由 provenance 中三个 manifest 与选材记录列出。新图形和案例构件均在本轮制作。

首轮读图中，全景可分出收件、登记者和闭卷三个架区，紫灰细骨料地面也能衬出架脚与座椅。近景中新盒里的文件只露出薄边，贴在金属柜上的拔手像平面图案，纸张在台灯下接近白片。通道图露出完整门洞和后方目录，门楣正下有过强的小片高光，红色地面边缘也过于笔直。第二轮据此修整文件、桌面分拣和门口的高光及收边。

首次启动的排队时间为 0.00 秒，混凝土 shader 的变量 flat 与保留字冲突，改名后重新启动。第二次排队 63.95 秒，Metal 成功加载，窗口迟迟未触发 frame_post_draw；终止该次挂起进程。第三次排队 43.12 秒，逐帧请求实际绘制，取得三张 1600 × 1000 图像。成功使用的临时脚本与后来统一的 capture.gd 经 diff 核对，内容完全相同。首轮共两次技术重试、一次有效提交出图。请见 evidence/pass01_overall.png、pass01_detail.png、pass01_transition.png。
