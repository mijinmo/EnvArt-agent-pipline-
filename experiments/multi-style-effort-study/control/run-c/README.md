## 参考与取舍

主参考右侧货架被成组档案箱填实，桌边停放蓝灰色搬运器具；冷色颗粒地坪反出模糊亮斑。辅助参考以红色地面、棕红木板和独立的绿底目录区分公共门厅。起点已经具备桌椅、照明和操作台；最大的距离来自薄弱的储存区、空白告示、偏灰的木饰面和门内外相似的地面。

首轮用冻结的钢架、纸箱及扫描地坪补全第二个库位。手推车的立杆、横撑、铲板、轮毂与轮胎按取货位置组装。为避免新建结构侵入门洞，薄饰面和铜色收口只覆盖门柱外正面。墙面沿世界坐标用 2.4 × 1.33 米分模，1.2 米横距布置小拉杆孔，混合两种尺度的扫描纹理；木材沿竖向重新着色。地坪降低底色及粗糙度，天窗聚光能量由 4.3 调为 3.7，工作灯由 2.9 调为 3.2。

首轮全景出现连续库位，近景仍难区分柜内分类，手推车与货架立柱重合。门厅两侧木板在标牌下方突然终止。第二轮把推车轻微移出货架投影，加装柜屉前片、编号卡，自绘归档宣传画和三种带签收栏的表单，延续至工作台。门楣木饰面闭合门头；门后铺设暗红色门厅地面，静态材质在指定世界坐标内使用扫描粗糙度控制绒面明暗。

最终近景的柜屉和标签清晰，海报在全景建立左侧边界；较远处编号需近看。货架仍复用同一种封箱形态，侧光下推车与深色支架局部重叠。门厅红色区域的边界和纤维表现偏整齐，近门照度较低。三张固定图未检验运动中的高光。

## 素材、验证与制作额度

钢架 steel_frame_shelves_01、cardboard_box_01、地坪、木材和扫描混凝土复用本组 Poly Haven CC0 副本。文件柜复用 3TD OfficeFileCabinet_01；[来源清单](provenance/detail_manifest.json) 与 [许可原件](baseline/licenses/) 随起点保留。柜面、推车与正面饰件为本轮补形，海报和三份表单为本轮原创印刷图。未引入新素材包。

两轮各重开场景，以 Godot Forward+ / Metal、1600 × 1000 和同一组三台相机输出。首轮首次启动遇到文本场景颜色小数缺前导零，未生成图片。修正一次后首轮三张和最终三张分别一次拍齐。三个图形启动的包装器排队时间均为 0.00 秒。两次成功退出都报告七个 Texture RID 释放警告；PNG 保存成功，已逐张查看。两轮约束 JSON 与起点逐字节一致，涵盖 17 个白盒体与 3 台相机；191 个冻结文件的 SHA-256 全部一致。
