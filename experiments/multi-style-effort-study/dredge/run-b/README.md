# Grey Reach · 港边检修棚

DREDGE 同输入环境美术试作。Godot 4.7.2，Metal Forward+。第一轮可编辑场景为 [pass01.tscn](pass01.tscn)。[总览](evidence/pass01_overall.png) · [工位](evidence/pass01_detail.png) · [入口](evidence/pass01_transition.png)

主参考右前港屋有深色、起伏的檐缘，灰橙墙面在木桩之间形成浅色面，主图后排小屋通过屋脊、桩脚和栈桥显出水上聚落规模。辅图的海水转为蓝绿，暖光集中于低空和航灯。两图无法确认检修棚近景的具体工具与木纹。沿用原场景的浮标检修主题，加入分层劈木瓦、外海网具棚和渔笼订单。远屋的墙、屋顶、山墙取自同一 Quaternius 建筑包，沿局部可视海岸以桩架落地。主棚保留原屋面承托，新增三种檐端细部。靠门两处跳台以按实测包围盒缩放的原装 Quaternius 货箱展示，边缘、薄台面和前后净空仍可通行。

首轮总览能读到不齐的檐和两组远屋。工位近景可读新绘领航图和装入原挂灯罩的灯芯，但木台、窗棂和桶身均陷入红褐阴影，棚口招牌被前排瓦遮住上沿。入口前景的救生圈失去浅色图案，云边显得过大。第二轮将针对这些实机画面修订。
