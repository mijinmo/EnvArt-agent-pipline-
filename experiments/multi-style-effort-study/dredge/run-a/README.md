# Sounding House · 港边检修棚

## 第一轮

参考主图右侧的港屋以深色毛边屋檐覆盖浅暖墙体，桩脚、拉索、近船与远屋错落。辅图在冷水和紫灰近岸之间留出暖天光，船灯和信标是集中亮点。近景维修设备的形式来自本场景对使用活动的设想。起点总览中红顶和水平直檐连续，门后的工位已有显著叙事道具，近景磨轮、桌面与小件的材质亮度接近。

第一轮使用可编辑的真实村屋构件和工位，给原屋面加铺四层错缝木瓦，增加小块不规则檐口。在检修区装入挂钩架与油衣，给木箱涂装斜撑、钉头和装卸标，建立低角度夕照、远水反光与局部暖灯。

[总览](evidence/pass01_overall.png) · [工作台](evidence/pass01_detail.png) · [入口](evidence/pass01_transition.png) · [可编辑场景](pass01.tscn)

三张实机图显示木瓦和油衣的固有色丢失，呈灰白色，且近侧檐尖挡住工棚字牌。工位设备虽有色相区别，阴面整体偏暗红。第二轮将修复新网格颜色传递，控制前檐的安装范围，并调整环境返光与岗位照明。跳台的木箱表面、局部水面反射及低日轮可保留。第一轮三机位一次成功，GPU 排队 0.00 秒，约束简表与起点逐字节一致。

## 第二轮与打开方式

用 Godot 4.7.2 导入本目录的 [project.godot](project.godot)，F5 打开 [最终场景](final.tscn)。在场景树 Harbor 下可直接编辑原屋片、木瓦层、门头、帆布、船托架、船壳、工位挂衣与工具组。pass01.tscn 独立保留第一轮的资源引用。

检查导入网格证实，GLB 已含逐面顶点色，但 Godot 导入的材质未启用顶点色底色。第二轮为这些实物显式指定读取 COLOR 的材质，保留宽面亮度分段。在原棚顶的三块木屋片上单独铺设修补帆布，两条边缘缝带沿坡向延伸，前边停在字牌上方。其余主屋仍使用四排错缝、有厚度和折面的木瓦。检修活动新增开盖漆罐、斜放的刷子、弯臂工灯，以及墙架上搁置的熟料搭接木艇。远处的机艇共用这副艇壳，加装甲板室、桅索与舷侧护舷。当地工装和工具是近看设计推断。对岸和外海只处理固定机位可见背景。

## 来源与参数

沿用 Quaternius Medieval Village MegaKit Standard、Fantasy Props MegaKit Standard 的免费 CC0 构件，保留原墙、木屋片、柱、窗、桶、绳、桌等可编辑实例。本轮直接复用包内 Peg_Rack 承托油衣。磨轮、锤及板料沿用 Kenney Survival Kit CC0。源码、发布方链接及许可保存在 [来源单](provenance/REFERENCE.md) 和 [许可目录](baseline/assets/licenses/)。本次使用共同起点的本地素材，无新增下载。新增木瓦片、油衣、帆布、工作灯、漆罐、艇壳与船舱均为本轮制作的独立 GLB。

- 房屋、设备和地面仍读取各自 UV 底色。wharf.gdshader 按材质角色对木料、铸铁和抹灰分色，在墙脚 0.71 米以下加入横向护板，边缘上方绘制旧漆线。原尺寸跳台的木箱材质按本地米制坐标绘制框、板缝和角铁，保持顶面几何及碰撞。
- 屋顶每个 2 米构件有四层折面，近棚则共享一张约 6 米宽的补缀帆布。painted_mesh.gdshader 读取线性顶点色，加入 0.043 倍固有色自发光，三档漫反射占 0.63，保留弱光下部分颜色。
- 天空使用两层三角插值云带和低位暖色日轮。水位 -1.35 米，静态 phase 为 0.36，阳光反射沿日轮方向集中。最终低角直射光与冷色广域回光共同照明，工灯在台面附近提供局部暖光。截图只评估静止画面。

## 最终读图与核验

总览里木瓦呈暗莓红色，工棚蓝绿帆布的外沿和补丁在落日下可辨。工位图里可以区分灰色磨轮、棕木架、红色漆罐、琥珀色油衣与蓝绿五金。入口图从救生圈和字牌望向内侧亮图板，原有门洞宽度保留。局限是远船被侧棚屋顶挡去大部分船体，两列屋脊仍较整齐；工位图的图板右角有工灯亮斑，长墙、货箱与原白盒路径仍有矩形轮廓。港屋与作业道具的组织属于本地样板，参考远图没有提供这些近景细节。

两个美术轮次，Godot 4.7.2 Metal Forward+，每次三张 1600×1000。第一轮提交 `a911895`。最终第一次导入时发现 TSCN 小数缺少前导零，已在启动出图前修复。最终首次出图的 GPU 排队为 41.29 秒；读图发现原顶片穿过帆布，于是按 glTF 三角面截面的上边界修正木瓦与帆布坡度，技术复拍一次，排队 0.00 秒。两轮出图合计三次，排队合计 41.29 秒。已逐一查看复拍的三个机位。17 个白盒体和三个相机的简表在两轮均与起点逐字节一致，清单内 185 个冻结文件 SHA-256 一致。
