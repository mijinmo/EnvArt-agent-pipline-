## 参考、范围与素材

共同输入的港村原图中，深色成簇屋顶压住暖墙，檐缘不齐，栈道木桩贯穿陆海交界。灯塔图中远岸岩块、深色树冠和暖天光分出距离。近景的检修活动为本棚的设计推演。保留原32米平台、既有棚屋、固定通道和海拔 -1.35 米的外海。

起点总览里，屋顶木板沿坡一铺到底，远景海平线很直，箱式跳台难以识别用途。起点工位中磨轮和架子近乎同色，三只浮标外形接近。过门图左侧墙有足够留白容纳渔具。共同资产中采用 Quaternius 的免费标准版 Medieval Village MegaKit 屋面、灰泥墙和窗等，以及免费 props 的工作台、桶、车、瓶、工具和绳。Kenney Survival Kit 2.0 提供磨轮及其他既有工具。两家的项目内文件均为 CC0；Quaternius 免费版仅含完整包的一部分。本轮无额外资产包下载。见 [资产记录](provenance/REFERENCE.md) 和 [许可原文](baseline/assets/licenses/)。

## 两轮制作和读图

1. 首轮在实际 Roof_Wooden_2x1 模块上覆四排末端破开的短木瓦，复用各模块自身变换。新增静态切面岛礁、树线、装运箱铁带、栓钉、编号牌、壁挂样瓶架和潮汐表。天空调至暖橙色，光照转向金褐。总览中远岛很高、太阳紧贴灯塔，四排檐瓦的暗缝密得发黑；近景中的潮汐表被海图截去左缘。通道侧的箱号可读，但左墙与磨轮仍空泛。提交 035085a。
2. 最终把木瓦疏为三排、更改背面法线方向及断口深度，拉近同片瓦之间的色值。把岛礁纵向缩至 0.55，后移 8 米，使用紫灰远景色。日轮移出灯塔轮廓。左墙在梁和挂钉上悬挂两只不同尺寸的编条渔笼。把棚内第三只同型浮标替换为待修的铜制潜水头盔，玻璃舷窗、格栅和肩盘螺帽均可编辑。潮汐表移至瓶架上方，磨轮单独赋石质条纹和金属轴件。最终总览里修理活动能从挂笼延续至台面，过门机位也能读到笼体投影。工位图保留了深色玻璃、铜框和阴面海图的层次。

屋瓦与岛岸 OBJ 的 UV.x 编码面色权重。facets 的 ink/light_ink 设置前后色域，最终 distant 用 shadow/sunlit 控制远岸空气色；grindstone 在轮体局部坐标中按半径刻同心纹。外海 phase 固定 0.36。当地几何和材质是该场景的风格假设。

## 验证与局限

两轮各保存并重开一次，使用统一 GPU 队列和 Metal 正常输出三个 1600×1000 机位。首轮和最终排队均为 0.00 秒，截图技术重拍均为 0。无头导入时沙箱阻止写用户级编辑器设置，项目资产生成成功，两轮图形启动均退出 0。已查看全部六张实机图，17 个白盒刚体与三台相机记录逐字节匹配起点。货箱表面附着件位于侧边，跳台顶面与门洞内沿保持可通行区域。

最终总览仍能看出屋面贴片循环与远岛规则的三角树冠，檐口盖住部分棚牌文字。细节图中头盔铜框偏亮，左侧近镜磨轮与木架仍有简模棱角。门洞、跳台外形和相机裁切受冻结空间限制。只评过三个静态机位。
