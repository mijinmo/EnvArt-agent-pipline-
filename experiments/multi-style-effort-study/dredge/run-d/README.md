## 从参考到维修棚

主参考右前方的港屋用深褐屋盖、起伏的尖檐、少量浅色墙面和深色支柱分层；左侧船体的浅色条纹在深水上很清楚。灯塔参考右侧较低的夕阳、冷水和分层的岬角用于划分开敞背景。工位上的铅锤、绞盘、图纸和维护小艇是根据港务作业做的延伸设计。两张远景参考能提供的近看依据有限。[港村原图](https://static.wixstatic.com/media/e609d3_1398d6b764a346a69d945f263e8aec34~mv2.png) · [灯塔原图](https://static.wixstatic.com/media/e609d3_e0eb701824064407a49c0e9a0590b2cb~mv2.jpg)

起点总览中大片浅红直板檐显眼，远海平行条带很密；过渡机位的货箱、栈板和门框色相接近。工位已有网、绳、浮标和地标图，磨轮的浅色整块、灯笼外的亮柱和空窗使材质比例不统一。保留敞开的工作面、浮标与原有吊架作为工坊核心，围绕检修船、测深工具和港务货箱补齐上下游活动。

## 素材和自制部分

- 保留免费 Quaternius Fantasy Village 的墙、窗、角柱、烟囱、屋面主体和山墙。沿原 2 米木屋面模块做三种四排错缝的劈木瓦，使用原屋面变换实例铺设；主棚有独立可调出檐。最终在山墙面增设竖板、斜边和百叶通风口。两座远处小屋沿用同一组墙顶实例。
- Fantasy Props 的 Workbench、抽屉、桶、卷绳、箱、挂灯与地面装卸工具构成近看主体。原 Stall_Cart 保留车轮、扶把、车架与 UV，在模型副本删除高于装载台的棚篷三角面，车上放置一艘自制搭接板小艇，墙上挂船桨。灯芯对齐到原灯罩内。保留 Kenney Survival 的原磨轮和支架，另建轴端、摇柄和小水槽。两套 Quaternius 只使用已提供的 Standard 免费内容；三包均为 CC0。原图集、模型出处与许可仍随冻结工程提供。[来源](provenance/REFERENCE.md) · [许可](baseline/assets/licenses/)
- 绞盘由线筒、铸座、黄铜轮和曲柄组成，最终版放线至台沿，接悬垂测深锤，台上另有记录簿。总览、工位和门洞共用实际物件。新制测深图包含等深线、探测路线、测点和罗盘。门牌、店牌和货牌的字已栅格化，工程启动无需字体。
- 木板着色器 wharf 按世界坐标生成错缝、缝隙和顺纹磨耗，build 分别指定甲板、货箱与直纹门柱。sound 的外海相位恒定 0.36，水面高 −1.35 米。dusk 的 sun_direction 在最终版为 (0.25, 0.020, −0.967)，云用三角插值色块，panes 的两层斜带用于概括静态窗面反光。它们是对参考画面因素的实现选择。地板宽 32 米及其通行表面保留。

## 两轮实机读图

第一轮总览里，小艇双色船壳、瓦檐和远海已经把维修区分开，但出檐盖过店牌，天空的白日盘很抢眼。过渡图中木地板与货箱都偏橙红，箱体的用途较难辨。工位图里灯芯已收进灯罩，绞盘与航图可辨，但墙斑强、磨轮缺轴端、绞盘线没有落点。

第二轮缩短主棚出檐，压低木瓦色值，加入可辨的浅色百叶山墙；缩小日盘，降低海上亮斑，调冷阴面、甲板和箱漆。货箱贴港务牌，工位补放线、铅锤与磨轮五金，东窗用低对比斜面色带。最终总览的店牌和山墙轮廓能一起读到，过渡图有清楚的入口和货物区，工位图能沿绞盘的绳走到铅锤。

最终三张图仍可见几项差距。远岸树尖和岸台的轮廓显得规则，点景小屋多被东檐遮挡；局部屋顶、尤其左侧檐口，还可辨认重复模块。近景鱼牌体量大，墙面仍有斑纹。货箱矩形与原跳台一致，相邻货牌也有重复。对水、窗和云仅做了固定机位静帧审视。
