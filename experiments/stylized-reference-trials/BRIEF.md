# 2026-11-19 风格化环境三方向试跑

用户要求继续按新版 skill 用独特游戏环境参考试跑，允许制作风格化 shader。指定模型沿用 GPT-6.2 astra。三个独立工程：Sable（室外沙漠补给/修理角落）、Hi-Fi Rush（室内工业检修角落）、DREDGE（室外港边仓储/修理角落）。这些是视觉语言迁移，不声称还原原游戏关卡。

三次 subagent 启动均显式设置 model=gpt-6.2-astra、fork_turns=none，未显式设置 reasoning_effort。工具约定为继承父任务；实际运行档位未核实。用户看到的 light 并非本次经过评测后选择的参数，因此本轮不能用于判断 effort 优劣，也不代表该模型的最佳能力。前两轮是 agent 自主制作/审图；第三轮另记录父 agent 看图反馈后的修订。

所有案例使用同一个原测试场白盒 source/whitebox.tscn（17 StaticBody3D）。保留源文件和全部原body变换、mesh尺寸、collision及通路；只有表面可换。局部完成门洞与东/后墙角工作区，坡道/台阶/跳台/出生区保留。允许本局部适配需要的视觉围护/檐棚（Hi-Fi Rush 室内需顶棚），不能新增穿过保护通路的结构。不得移走原墙体，外部海面/沙漠仅为辅助远层，不扩建全场。

各案例选择能看清自己的局部的三个观察机位 overall、detail、transition，先冻结；白盒、首轮、最终和 shader 对照使用同机位。不同方向不强迫用同一构图，但跨游戏图片不是受控A/B。

先找环境展示清楚的参考，记录主/辅用途、源页、具体图片或视频时间戳。真实授权素材优先，允许原始素材缓存，不读旧完成美术场景/构建脚本抄布局。可以为有证据的目标特征制作专用 shader；留下同几何、相机、灯光与合理基础材质的对照，不把全局调色或灰模对照当作 shader 成功。

产出：可编辑Godot工程、源资产与许可、参考/候选取舍、首轮和最终三机位图、shader对照图及参数说明、实际不足。只做导入/加载/实际渲染与直接受影响约束检查，不做控制器或通用测试框架。每个独立阶段只提交自己文件。原主工程既有51个.import修改不碰。

共同源白盒来自 ../whitebox-lighting-study/source；Godot 4.7.2 / Metal Forward+。当前 Control 版本与所有旧案例保持不变。本轮自制 shader 的效果和多方向质量仍待实际出图评价。
