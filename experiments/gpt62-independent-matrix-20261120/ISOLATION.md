# 本轮隔离边界与预检

## 已实施

正式制作使用独立 `codex exec`，每次新上下文，模型 `gpt-6.2-astra`，显式设置本组 effort。未使用宿主项目的 linked worktree；每组随机目录单独初始化 Git。制作目录都位于 `/private/tmp`，宿主归档位于 `GodotProjects`。协调者保存配置、队列和汇总，制作组没有其读取权限。

- shell 权限采用 Codex 自定义 profile：最小系统读取、本组读写、所需安装工具读取；拒绝 `/private/tmp`，只重新开放本组目录。宿主项目和 `.codex` 会话目录不在允许读取的集合内。本组 `.git` 显式可写。
- CLI 忽略个人 config/rules，关闭 apps、plugins、browser/computer use、image generation、hooks、memories、shell snapshot 和进一步 multi-agent 等入口；同时在制作任务中禁止通过其他工具/本地服务绕过边界。保留公开网页搜索、文件编辑、shell 与本组图片查看。
- 每组有自己的 TMPDIR、下载目录、XDG 缓存、Blender 用户目录和完整 Godot 应用副本；应用副本使用 `_sc_` 将编辑器数据留在本组。项目唯一 config/name 只用于分离 user://，不作为美术变量。比较输入哈希时只归一化此名字；同一游戏其余输入完全一致。
- CLI 最小文件权限下，Godot 图形进程无法正常启动。因此图片经中性 `render.py` 请求，由协调端依次运行。渲染进程仍有 macOS Seatbelt 文件限制：拒读/写全部其他临时目录、宿主项目、全局会话与其他 Godot 用户数据；只开放本组目录和本组 user://。渲染进程网络关闭。系统图形服务与其他普通系统路径仍可访问，系统/驱动级缓存未逐项隔离；这不是整台虚拟机隔离。
- 渲染服务仅接受本组导入或本组 `.tscn` 的固定机位截图。场景、输出必须留在本组，输出目录不能已存在；冻结 capture.gd/views.json 的哈希不符则拒绝。请求/响应只含本组信息。

## 预检证据

2026-11-20 用人工建立的无项目内容哨兵文件测试：CLI shell 与专用渲染权限均返回 `own=READABLE, peer=DENIED, archive=DENIED, own_write=OK`。专用渲染权限下 Godot 4.7.2 Metal Forward+ 成功导入同一白盒并生成三张 1280×800 图片，退出码均为 0。

短 CLI 模型预检成功；正式首批三个会话的运行 `turn_context` 确认为 GPT-6.2 Astra 的 low、medium、xhigh。其余组启动后逐一核实，不能仅用启动参数替代实际记录。

图片工具的本组读取已成功；预检 agent 因权限声明而未调用禁止路径，所以不能声称实际测得图片工具对跨组读取的拒绝。工具入口关闭也不等于协议中绝无相关工具名称。最终须检查实际工具调用；本文件不会把未验证的部分描述成绝对安全保证。

## 收集与最终审计

协调者在每组停止后收集 Git 管理的场景、素材、许可和图片，排除私有会话、缓存、下载包与未获再分发许可的参考原图。收集不会反向写入其他制作组。少量制作组只保存在私有目录的技术修复前原始截图，由协调端在制作停止后补存至 captures/technical，单列来源和哈希；这些排错图不加入两轮美术匿名排名，原制作场景与文档不改写。最终另附每组实际模型/effort、输入哈希、阶段提交、使用量、工具访问审计与不能确认的范围。

若发现读到其他组美术/解法内容，该样本不得用于独立结论；元数据或中性工具接触也须说明。不把“记录中未见跨读”说成“所有访问面都已证明不可能跨读”。

## 匿名视觉评审的边界

每个游戏的六组制作停止并完成收集审计后，另建一个视觉评审包：随机 A–F 标签下的 36 张首轮/最终原图、三张共同白盒、该方向冻结参考和中性任务说明。包内不含 effort、用量、制作源码、制作自评或素材路线。标签映射由协调者保存；制作组不会获得评审包或评语。

四个游戏分别由新的 CLI 上下文评审，统一使用 `gpt-6.2-astra / xhigh`，关闭网络、委派和宿主插件，文件权限只开放本评审包与必要系统工具。评审要求实际查看全部原图，再给出整体梯队及参考贴合、内部统一、素材适配、功能/叙事细节、光影/空间层次五类判断。允许并列，不能从图像推断素材许可，也不评成本或运行速度。

协调者将核对评审调用记录、声明的看图范围及所有评审输入哈希，保存原始判断，再依据映射和实际用量形成管线取舍。协调者知道映射，其补充复核不称为盲评。评审开销不混入制作 agent 用量。每个方向只有一个模型评审，不能视为多人一致意见或用户美术验收。

HTML 的隐藏档位是便于用户先看图的显示功能；页面代码和图片路径仍含对应关系。正式匿名评审使用上面的独立图片包，不读取 HTML。
