# 固定机位复看

## First

已从保存的 first.tscn 重开，以 door、props、close 三机位出图。门洞仍可读穿；红屋顶把入口与后面的工棚连起来。工作台、秤、刀、收货箱及浮子的支承关系在 props 中可辨。近景能读出秤面、结绳和交货记录。

| 实图位置 | 首轮观察 | 本次修订决定 |
| --- | --- | --- |
| door 上半与门后 | 大块米灰天空与背墙挤在同一明度；后墙像平直院墙。箱件侧面亦缺少装卸留下的识别。 | 拉开海边天光与门楼的冷暖；在既有边界补远岸层次、后墙开口和箱件的吊装细节。 |
| props 屋面与前缘 | 斜梁穿出红屋面，成为亮起的平行木条。棚前深浅区域接近，难以区分檐内与外侧。 | 将椽收进屋面，让开敞侧的天光和台前一盏局部灯承担不同区域的照明。 |
| close 台面 | 杉木台面和称盘偏黄，鱼腰只有一片发白的亮面，轮廓下方有空隙。木墙亮划痕重复，挂牌与秤盘重叠。 | 冷却棚的底色，降低木墙划痕，降低鱼的落点，重做侧腹色区与头部标记。将记事牌从秤盘后移开。 |

## Final

- **door**　门楼红顶在蓝灰天光和横云前有了清楚的轮廓。双侧港灯、深框号牌、货箱板端和箱签在同一视线，门洞内可以看到后场干地。后墙面积仍很大，远门从此角度只露出一部分。
- **props**　棚下左侧的吊具落到盐桶旁，工位依次可见贝碗、案板、秤与收货箱。回墙外侧露出一段蓝色海湾，地面仍连续可走。首轮屋顶上的连续木条已收进坡面，屋面上仍露出少数木端。
- **close**　鱼身降低、转向后与案板更贴合，松木台的橙黄减弱，成对浮子和收货网兜的位置可辨。鱼头在固定近景里仍较暗，侧腹细纹不易辨认；秤盘与记事牌底边仍然靠得较近，小字比大号牌更软。台下物资部分被原摊凳的横撑遮挡。

## 技术修复记录

最终场景首次打开时，环境子资源引用了排在其后的天空资源，Godot 解析停止，未产出图像。调整定义顺序后，三机位均可加载。第一次有图的技术检查中，天空呈整片米灰；最终副本的非体积雾以默认值覆盖了全景纹理。仅将 fog_sky_affect 设为 0，使已有天空正常显示。修复前图和场景存在本组 .work/technical，重拍使用新目录，交付 PNG 为重拍原图。整个美术修订只进行一次。[Godot Environment 文档](https://docs.godotengine.org/en/stable/classes/class_environment.html#class-environment-property-fog-sky-affect)

Git 默认全局配置、系统缩略图工具及编译器启动包装的系统临时缓存受到沙箱限制。提交使用禁用全局配置的本组 Git 调用；看图使用本组文件，检查用缩图写入本组 .work。Kenney 站点直接下载返回 403，实际压缩包改从作者在 OpenGameArt 发布的公开文件取得。
