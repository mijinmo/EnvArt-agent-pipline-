首轮与终版均使用原三机位和视场角。终版同时改动几何、摆放、材质和照明，图中的变化应按整轮看待。

## 技术核对

- 导入、重开和两轮实图都经本包的 render.py 完成。终版导入时发现门灯能量写成缺少前导零的小数，已修正场景文本并重新导入，随后才生成终图。两轮 PNG 均为 1280×800，首轮依赖与截图和首轮提交一致。
- 以项目默认入口启动，并对照白盒逐项核对原物体。17 个 StaticBody3D 与 18 个 CollisionShape3D 的变换相同，碰撞形状资源及启用状态一致。对终版可见网格检查门洞内缘，距边界 1 毫米处没有三角形进入净空。
- 本机沙箱拒绝了系统图像工具的默认临时文件写入，以及 Git 对全局配置的读取。参考缩览改存本组工作目录，Git 使用本组配置。终版的本地无窗口核对还返回 macOS 系统证书读取提示；入口完成加载，Metal 截图日志记录了三个机位。
