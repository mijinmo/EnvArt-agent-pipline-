# 三机位复看

## First

已重开 first.tscn，查看 1280 × 800 的 door、props、close。门冠、吊秤和三角支棚把两个工作点连在一起，秤盘、垫布、单据能交代货物正在称量。

- door 的门头字能读，门柱和字牌正面却压得很深。门后石墙与远山轮廓过于平齐，近处箱角的灰色金属盖过印记。
- props 的杆索有明显技术错误。应该沿棚沿和拉索连接的短圆杆竖了起来，顶部出现一排尖刺。秤梁及包绳也受同一变换问题影响。底板和大片沙地之间缺少实际搬运留下的过渡。
- close 的表盘轮廓明确。秤后大面积同色砌块、盘下第二只盘与黑色直杆挤在同一条视线上。货桌以外的工序只靠小箱与瓶子交代。

本次修订围绕称量工位展开，恢复真实受力连接，给墙面一张可近看的运输线路图，给沙面留下选择性的通行痕迹，调整门冠的亮暗与远山分层。保留首轮场景、依赖和原三张图。

## 首轮技术记录

首次重开时，部分圆件的子资源标识含小数点，Godot 输出 ID 字符警告并继续完成三张图。杆索的轴向错误与此独立。两项在 final 的独立场景中修正。

## Final

按相同三机位重开、拍摄并逐张查看。door 中门头的字与翼形冠饰独立于天际线，跨场旗索连到右侧棚顶。前景货签与工位沿用同一套字形。props 中棚缘拉索落在端柱上，青绿卸货垫与沙地脚印连到桌前，棚影清楚划出工作区。close 中可沿墙座、斜撑、吊点、表盘、三根吊线读到盘上的盐包，左侧线路图和右侧卷图相互呼应。

固定 props 视角下，近侧支柱仍遮住线路图的右端。近看盐包侧面、木箱与桶面较平，材质信息比石墙少。门后连续墙段的砌块节奏仍偏整齐。远山只在观看距离上承担空间分层。比较图见 [首轮](captures/first) 和 [终稿](captures/final)。

## 终稿技术复拍

第一次 final 复看发现，删除桌面备用盘时误删了属于吊秤的同名托盘。三个排错原图保存在 [missing-pan](captures/technical/missing-pan)。仅恢复独立命名的 SuspendedBrassPan，使用新输出目录复拍，再将核对过的三图归入 captures/final。最终捕获日志记录 Metal Forward+、三机位完整写出及退出码 0，无场景 ID 报错。此次复拍未改灯光、位置构图与材质。
