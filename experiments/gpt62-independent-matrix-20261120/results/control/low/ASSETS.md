# 素材与小样
模型及扫描面来自 Poly Haven 的免费 CC0 库，可商用及再分发。完整许可在 assets/CC0.txt。各目录与源 ID 同名。模型使用 1k glTF、二进制网格及随附纹理，保留原 UV、法线和打包材质通道。桌柜按米制放置并沿墙旋转；台灯缩至 84%。扫描面使用 1k JPG 漫反射、OpenGL 法线和粗糙度，世界投影配合现场染色。

小样 A 的墙体在转角能读出冷暖变化，但从桌面直至顶棚都被同一种细斑占满。B 的半高漆面把灯臂从斑点背景中分离，也给桌柜提供了一条连续基线。选择 B，保留上墙的扫描尺度。门套、灯壳、标识、表单及梁按白盒尺寸制作。

## 修订追加
同为 Poly Haven 免费 CC0、1k glTF。金属凳和转运车分别缩至 83% 和 80%。壁灯选择 B 款，便笺选择 A4 纸堆，二者编辑 glTF 的场景根与原点，各自仅导入一个款式。
