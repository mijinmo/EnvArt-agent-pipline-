## 场景与证据
sample_a.tscn 与 sample_b.tscn 对照整面混凝土和半高护墙。first.tscn 保存第一次完整布置，final.tscn 保存一次自主修订。四组固定机位截图在 captures 下各自同名或连字符目录。导入和截图均经 python3 render.py。

局部围绕门洞与右侧墙边工作台制作。打开场景的 Art 节点可调整建筑、灯、标牌、表单及家具实例。BaseLab 保留原控制器和碰撞。局部之外仍为测试场。图像方向见 RESEARCH.md，素材与许可见 ASSETS.md。终图的表单小字、地面颗粒和顶棚暗缝见 REVIEW.md。
