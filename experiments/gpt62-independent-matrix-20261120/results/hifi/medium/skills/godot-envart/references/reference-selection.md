# Find references that explain the environment

Use before art direction when the agent chooses references, or when supplied references leave important environmental questions unanswered. The objective is sufficient visual evidence for the work area, not an attractive collection of game publicity.

## Search by environmental need

Start from the chosen game/art direction AND the relevant spatial type, location and activity: interior archive, service corridor, ruined threshold, forest path, maintenance station. Search for the environment, not just the game title plus “wallpaper”. Prefer identifiable shipped-game walkthrough frames, photo-mode captures, environment-focused screenshots, and environment artists' documented work/breakdowns. Developer presentation imagery can help when its scene and rendering context are clear.

Use the available search/browser tools and inspect actual images rather than trusting thumbnails or captions. If a video is useful, record the exact timestamp and inspect a representative frame; do not imply a clip was watched if it was not accessible. Existing source-verified cache is useful, but reassess its suitability. Do not keep searching solely to meet a fixed image quota.

## Qualify each image

Ask whether the intended wall, floor, architecture and prop relationships can actually be read at useful scale. Look for a clear environment-wide view and, when needed, a detail and a transition/adjacent view from a coherent area. Two complementary readable images can be better than ten unrelated images.

**Primary environment evidence** can support geometry/proportion, surface behavior, activity/density or stable lighting. Specify which of these is visible; no single image must prove all of them.

**Supplemental mood evidence** may explain palette, tone or an overall artistic intention but is obscured, heavily processed, conceptual, staged, from another location or from an uncertain build. It cannot alone establish asset shape, room connectivity or permanent illumination.

**Reject for this task** when the needed environment is unreadable or misleading: character key art, portrait/hero showcase, a wall hidden by explosions, heavily blurred scenery, severe grading, low-resolution crops, wrong spatial type, unrelated fan reconstruction, or an image of uncertain identity that cannot be qualified. Record only consequential rejection reasons, not every search result.

Promotional origin is not an automatic rejection: an environment-led promotional screenshot with legible scene detail may be useful. Conversely, a gameplay image dominated by combat is not automatically a good environment reference. Label concept art, pre-release captures, mods, fan work and offline renders; they can inform an expressly chosen target but must not silently stand in for shipped gameplay.

## Build a coherent set

Keep the primary set tied to the same visual direction and compatible location/conditions. Do not combine an exterior hero shot, a different game's furniture, and unrelated cinematic lighting into an accidental new style. When mixing is intentional, state which source owns architecture, surfaces, dressing and lighting, and identify tensions before asset sourcing.

Interpret unobscured spatial relationships first. Characters, UI, particles, battle flashes, motion blur and depth of field are separate from permanent environment content. A wall joint visible in one location does not prescribe a repeating grid everywhere. A bright explosion cannot specify the room's baseline exposure or light rig.

Keep the source identity attached to every viewed image. With batched results, explicitly confirm which file is which; never infer identity from output order. Use the same approved evidence set through candidate review and scene review; changing the reference direction reopens affected asset decisions.

## Minimum useful record

Use the task entry or existing brief; create a separate reference list only when needed:

```text
ref_id: exact local image / source page or video URL + timestamp
context: game, location, indoor/outdoor; gameplay / photo mode / concept / promotional / unknown
role: primary environment / supplemental mood / rejected
supports: specific visible architecture, surface, prop relation or lighting evidence
limits: occlusion, combat light, missing floor, build/mod uncertainty, hidden geometry
decision: selected / supplement only / replace; why it matters for this slice
```

Record source attribution and source-use conditions appropriate to reference use. Looking at a game image for visual study does not grant rights to extract or ship its assets. Do not bundle reference media for redistribution without checking the applicable rights; keep source links when redistribution is not established. Asset licensing is a separate sourcing task.

## When evidence is insufficient

Continue independent asset/license investigation if useful, but defer reference-dependent architecture/material conclusions. Seek a clearer environment view, a complementary camera or the user's intended location. Within an already specified style, the agent can choose better references autonomously; ask only when resolving the gap would change the requested direction or scope.

Deliver a small qualified reference set before commissioning extensive new production. Do not declare reference selection complete because familiar game names or high-resolution images have been collected.
