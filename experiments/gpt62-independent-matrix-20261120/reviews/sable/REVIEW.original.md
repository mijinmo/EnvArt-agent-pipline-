# Sable 门洞与货运墙角 · 匿名视觉评审

**整体首选 A，次选 F。** A 最有说服力的一处，是秤、单据和储水桶在同一张近景里都有各自的使用位置。从入口望过去，红棚把这一小片工作区从开阔沙地中标出来。F 的长处是把货物如何运到秤边做得可信，车柄、车轮、袋口、砝码盒都经得起近看。A 的中景损失了一部分墙图，F 则在中景遮住了墙旗，门侧两个台体的用途也更含混。

## 参考与共同白盒

- **参考 01 是建筑与材质的主要依据。** 右侧圆塔的浅色砌体承着一圈深色平台，石缝里有不规则缺口，穹顶磨痕和远山层线各有自己的方向。门洞局部可以借鉴这种区别材料与远近的画法，塔的高度和轮廓没有可比性。
- **参考 02 是装具与露天空间的主要依据。** 杆索收在可见的节点上，箱、网和梯子沿平台边缘布置，底下的沙地留给车身、轮环和梯子的投影。这里可借鉴物件怎样依托工作面，网具的实际用途属于这辆移动载具。
- **参考 03 补充棚下的使用尺度。** 靠边叠放的包箱与地上分开的矮垫、容器各成一组，暗处仍看得清织物轮廓。人物和对话框挡住地面中部，三份参考都没有给出固定货运柜台的完整操作近景。
- **共同白盒提供遮挡基线。** door 已有独立门框和右前方高低两块，props 的视点朝向空墙角，close 更贴近墙面。原图已有墙角斜影和墙外短台。评的是各组怎样利用这些体量、怎样让新物件投影与工作区发生联系。

## 五项偏好

### 参考贴合 · C

C/final/door 的远山用少量浅线分出岩层，门柱用较深的接缝分出石块，外侧弯管的箍带又是另一种轮廓。这种随材质和距离改变线条的做法最接近参考 01。props 的红棚在支点间下垂，深色杆索前后分开，墙边小车载着袋与卷材，让人想起参考 02 平台边缘的装具。close 右墙褪色的日纹透出石缝，左侧织旗的纹边却还清楚。短板在近景木台，厚板和支脚大片同色，木、石之间的表面差异尚不及参考。

### 内部统一 · A

A/final/door 的站牌和黄旗上是同一鸟形，转到 props，红棚上的鸟形直接标出工作区。近看地图题头、秤座、供水牌沿用门牌的深青，桌旗和地毯共享菱纹却改变了颜色和纹样尺度。去掉可读文字仍能认出同一站点。E 的太阳与山形标也很一致，但 props 墙上成组重复的砖框和大块矩形吊旗，使墙与布的差别变弱。A 自己的招牌边框、织纹也比墙皮整齐得多。

### 构件与道具 · F

F/final/props 左下手车有辐条轮、双柄和停车支脚，车板宽度容得下并列的扎口袋。close 的砝码盒敞开，盒内陈列着大小不同的砝码，双盘各有吊索，横梁、表盘和底座的关系清楚。右端卷毯露出卷芯，和门内框的金属包边、墙面的错缝形成材质差别。局限是凳脚和桌腿仍显整块，手车柄在 close 左缘与桌角贴得很近。C 的带拱架小车也有运输用途，近轮被矮凳挡去一部分。

### 功能与表面细节 · A

A/final/props 把托板上的袋装货、称量桌和靠墙取水处排成三组，中间地面留给人靠近。close 里包裹标签朝外，纸旁是印章，盘绳挂在路线图旁，右侧阀轮、横桶龙头和下方小杯互相解释。仅看物件的位置也能读出工作内容。墙皮下缘有断续剥落，桌旗却有整齐收边，细节密度随使用位置变化。相比之下，B 的墙图和桌图指向同一条路线，桌上物件与实际货物的联系较弱。A 的水标和路线图都很抢眼，中景又被棚沿切去了部分信息。

### 光照 · D

D/final/props 的棚影从左墙落到横桶和木地面，前方日照沙地上能辨出细绳与小旗的投影，沿着影子可以找回头顶构件。close 墙角留一条暖亮面，阴影里的浅色桌布把深色印章、笔和秤盘托出来，桌下的红包仍有轮廓。door 的深绿门框衬在亮沙前，也交代了露天入口。D 的墙面斑点在暗处稍抢秤的轮廓。A 的阴区也保住了地图与砝码，但 close 中秤面和后墙的明度更接近。

## 六组首轮与终图对照

以下每组均按 door、props、close 核对同机位的 first 与 final。整体档次依据终图。

### A

door 的高门楣和窄黄旗先定入口，右边低一些的红棚露出第二个使用点。props 的麻袋垫木板、秤桌铺织物、陶罐落在横桶旁，同一面墙下能分清干货和取水处。close 的桌腿与小凳较厚直，桶端切面也偏硬。

**修订得失**　door 中棚面从窄红带展开，鸟形可辨，门脚原先浅淡的方框变成格栅，后方台体换深青顶。props 的前柱退到左缘，秤桌更完整，代价是降低的棚沿盖住路线图上边。close 把图移到秤左，简化桌旗纹样，并在横桶上方补出双管、阀轮与水牌，首轮已有的秤、印章和桶因而更好读。

### B

door 的深绿门柱和浅色站名在远处认得快，props 用桌子居中、箱桶分列两侧，入口关系很直观。close 的瓶有明显圆滑高光，箱框和桶箍却厚钝，背景和木面少有能区分材料的细线。

**修订得失**　door 把纯色后墙与前景台体分出砖缝。props 中三只叠桶向右错开，原先与桶重合的后侧棚柱露出柱脚。close 从一只绿瓶的空桌变成有图纸、桌牌和小件的收发桌，并铺了深色地垫。岗位更明确，但墙图、桌图重复相近的路线图形，棚内货物本身几乎没有补充信息。

### C

door 的门侧管、旗杆和箱扣让砌块门洞与装运联系起来。props 留出车辙通向的开阔沙地，close 的挂秤旁紧接着装袋、卷材的小车。矮凳在此角度遮住近侧车轮，厚桌板占了较长一段缺少变化的近景。

**修订得失**　first 的 props 有多截黑线突过棚沿，右边旗片之间的线还断开。final 的拉索连续，布沿与支杆的高低清楚了。close 的秤由半边暗壳挡住刻度、吊线相交，变为正面刻度、三角吊线和装货的秤盘。door 两个台体加上不同色箱板和向上标记，更像待运货箱，但也从门洞分走注意。

### D

door 的拱窗和门脚铺石给墙厚与地面尺度提供了依据，props 用木地面和窄毯界定办理处。close 的地图、悬臂秤和桌面单据能顺着读过去。外面两只箱的灰色包框显著厚于木板，近景石墙又几乎每块都有密点，与细小器件争夺注意。

**修订得失**　first 的 door 和 props 有许多尖长线段从红棚穿向天空，close 连秤盘下也叠出一个浅盘。final 的旗绳连成弧线，墙托、斜撑、吊盘之间能逐段看清。墙图、章和朝向桌前的淡脚印使柜台有来客的意味。props 的前柱仍遮住墙图右侧，放大的箱牌又给 door 增添了一个醒目焦点。

### E

door 木箱的板缝、角钉和搬运箭头能从入口读出，close 的天平两盘及桌面砝码也容易辨认。props 的尖角棚边和菱纹地毯呼应，但墙上重复的小砖框看起来像一排排画在表面的符号。角落的桶、箱和矮柜挤在一起，难以分清前后。

**修订得失**　door 从深绿盾纹柱变为浅石分段、挂编号牌的门柱，两个素箱面补了板条与货标。props 的棚向前展开，右墙添了百叶，左墙能看到管线。close 左缘原来挡住大桶的前柱移出了画面，秤左的瓶与秤杆也分开了。中景的前柱则仍压在左侧叠桶前，大块素色吊旗占了棚前的天空。

### F

door 的浅石外框、青灰内框与门脚铺面把入口厚度交代得清楚。props 的手车满载扎口袋，停在秤桌一端，另一端才是储物架，进货方向很自然。close 的器具最耐看，门侧两座浅色台体则稍显空。props 的前棚柱也挡了部分墙旗。

**修订得失**　first 的 door 中两侧突出石块夹住红招牌，内框几乎成一整块暗面。final 让完整站名与 07 露出，内框分出箍带和接缝，橙色前景体改为浅石身、深顶面。props 和 close 把原来叠在秤后的墙旗移向左侧，开盖砝码盒、卷毯与桌边垂布各有位置。近景图形清楚了，中景仍受前柱遮挡，门前台体也失去首轮醒目的颜色区分。

## 可见约束与判断边界

- 共同白盒 door 已有门右高低两块，props 的墙外短台和 close 的直角墙也已存在。六组 door 仍能透过门看到后方，前景台体各有遮住棚下低处的视角。这里只评包覆和遮挡，单张透视图无法量出净空。
- A/final/props 棚沿横过路线图上缘，F/final/props 左前柱横过称量墙旗，D/final/props 前柱切到墙图右端。三处在各自 close 都能看清，属于特定机位的遮挡。
- B/first/close 右侧棚柱落在桶端轮廓内，B/final/props 两者已分开。C、D 首轮棚沿外的断线或尖刺在共同白盒里没有对应物，两组 final 的相应轮廓已整理。
- C/final/close 的矮凳遮去部分车轮，F/final/close 左缘车柄与桌角投影相切。画面可以确认轮廓关系，实物间距与碰撞仍待场景实测。

门洞 1.2 米净宽、2.3 米净高是任务给定的尺寸。三机位只能确认开口的可见轮廓，无法验收尺寸、范围边界、坡道、台阶、跳台和碰撞，也看不到移动视角下的背面与接合。素材来源和许可另需独立证据。六组在近景材料变化与构件接合上离参考原作仍有距离，本轮尚未获用户验收。
