# DREDGE 门洞与岸上交接角盲评

**整体首选 C，次选 D。** 同档由高到低依次为 C、D、B 与 E（并列）、A、F。

C 的 door 从鱼形屋脊标、门柱灯和救生圈就能认出交接入口；转到 props，右墙端的吊臂伸向水面方向，棚下仍是一块面向干地敞开的木台区；到 close，秤盘里的整鱼、砧板上的横切面、刀和手边的货箱把称重与分切连了起来。这三个距离都能交代同一个地方，是 C 领先的原因。代价是石铺纹样偏密，棚灯把告示照得比鱼更醒目。D 的建筑与远岸最贴近主参考，门口也更清爽；近看吊秤、壁架与台面之间的关系稍弱。B、E 同档，B 胜在门棚统一，E 胜在工作灯下的台面。A 的称重交接可读，F 的近景仍较依赖鱼牌说明用途。

## 参考与共同白盒

参考 01 的前景是成片深红屋顶、浅墙和深窗洞，中景木桥从建筑之间伸向水面，远岸树林在雾里变浅。它给出了港口的体块、配色和前后层次。参考 02 的近处能辨出板路、栏杆、斜撑和桥缘轮胎，柱灯沿着人能行走的边界排列；暖光只照亮局部，暗处仍保留结构轮廓。这张官方壁纸适合观察灯与木构的关系。

参考 03 右上角标有 PRE-ALPHA BUILD。鱼商手下的整鱼、切口、刀刃与台沿同框，可用来判断切配动作是否说得通。前景为二维对话绘制，画面又有界面遮挡，门洞尺度与三维布局仍以本次白盒为准。

白盒 door 里，青色门形与右侧墙角隔着一段网格干地，右前和右中各有一块橙色体块。props 能看到两道墙相接、右缘矮块与敞开的台前位置；close 原先只有空墙角和从墙面延至地面的斜影。以下用 door 看入场关系，用 props 看整段作业区，用 close 看器具如何使用。

## 五类偏好

### 参考贴合　D

D 的 door 把暗红山墙屋顶、奶油色墙面、厚木窗框和深窗洞组织成前后两层建筑。props 从檐下三角撑看出去，越过干燥石地才见窄水面、折面岩岸、松林和条纹灯塔。这一近远关系最贴近参考 01，木构受力关系也呼应 02。短板是 close 的绿墙木纹和 door 的石面斑纹比参考的大色面更抢眼。C 在墙端小吊臂与岸上操作区的关系上尤其贴近 01，门后的连续板墙则缺少 D 的建筑纵深。

### 内部统一　B

B 的 door 从门柱深色包边、浅墙到右棚的明暗分块都沿用同一套构造；门楣深绿鱼牌的鱼纹、细框和 04 编号，在 close 秤后的登记牌和右墙红牌上有变化地重复。浮标只占一小块红，旧木和暗青墙仍连成一体。较弱处在 close，登记牌的小字发糊，浅色表盘与布巾比后方木箱更容易辨认。F 的暗边与平色也很一致，但 props 的右墙大块留空，门与后方建筑的前后层次较薄。

### 构件与道具　C、D

C 的 close 能顺着上环、表盘、下环和三根细吊索看到秤盘怎样承鱼，鱼眼、背纹和断面让整鱼与切块可分；props 还能看清吊臂的斜撑、滑轮和垂环。鱼头尾伸出浅盘较多，左侧操作空间显紧。D 的 close 用木悬臂承住吊秤，台架有横档和紧固件，props 的提梁桶、满鱼箱及卷绳与台高互为尺度。两者分别胜在器具怎样工作、构件怎样接合。D 的秤索与后方壁架在 close 叠线，托盘轮廓不如 C 干净。

### 功能与细节　C

C 的 close 把有条纹的整鱼放在秤盘，砧板上留带皮横切面、鱼段和刀，台沿垂布，右手边箱中另有整鱼。物件所处的位置已能说明称重、分切和分装；props 的浮标与收挂的网靠墙，台前还留有操作干地。参考 03 支持鱼、刀、操作面的功能关系。C 的石地纹样铺得太满，亮招牌也分走了注意力。B 的台秤配登记牌讲清了计量，切配前后两种状态的区别较弱。

### 照明　E

E 的 props 能从左墙灯找到暖光落点，close 里悬鱼在墙上投下清楚的影子，鱼背、砧板和条纹布沿着受光面依次可读。往右到吊秤和地盆渐冷渐暗，棚外仍能看见天光与远水。这个亮度分布把视线留在操作面，接近参考 02 用小范围暖灯标示作业位置的方式。损失在右角，深网绳和桨柄沉入暗木条。C 的门灯与棚灯能隔着庭院对读，但 close 最亮的奶油色告示先于砧板吸引目光。

## 六组候选与自主修订

### A

door 的四坡红顶、黑底鱼牌和 PIER 04 容易认，门柱和前景箱的红条互相呼应。props 左侧鱼箱、中央砧板和右侧台秤构成交接台。close 的黑色 FISH EXCHANGE 大牌压住一部分窗格，面积远大于鱼，秤后的两圈挂绳与右墙规则网格也显得较平。

**首轮到终图**　door 的箱面从大片棕色变成有竖板、横档和红记号的货箱，门柱多了一盏灯。props 的空箱装入鱼并挂上批次签，右墙挂网；close 原先白碗的位置换成带表盘的台秤。交易用途清楚了，终图棚下较冷较暗，桌下小凳与台腿较首轮难分。

### B

door 的山墙和双门灯框出入口，右棚用相同的红顶和深木边收口；props 里靠墙挂绳、桶顶盘绳、台面与木铺操作区都有各自位置。close 的秤面、砧板上的深背鱼和台边布巾可单独读出。右角鱼箱与浮标落在深阴影里，屋面还有几段短木端露在红面之上。

**首轮到终图**　door 的天空有了云层，货箱正面补出横档与三道浅色标记；props 右端墙外可见远水，左墙可见垂环，右侧箱里有鱼和网。close 的鱼由明亮浅色变为深背，台沿多了布巾。首轮满台偏黄，终图的桌面与冷背景分开了，右角货物及称重牌小字也随之更难读。

### C

door 的鱼形屋脊标、红顶、门灯和救生圈构成清楚的入口轮廓；props 的木铺工作带在石地边收住，墙端吊臂向外挑。close 的悬秤、分切板、布与箱在伸手范围内形成一组，右墙网和桨把注意力留给台面。浅盘上的鱼有些长，石地与灯下告示又各自争夺焦点。

**首轮到终图**　first 的秤盘空着，整鱼在砧板上；final 的 close 把整鱼移到秤盘，秤面从几十公斤量程改为个位数公斤，板上出现切段、鱼片与刀，右箱有鱼，台边搭起条纹布。props 墙外多出清楚的吊臂和水面，door 在屋脊后能见层山。交接过程更具体，左台角也更挤，棚灯把小了一号的告示照成一块亮面。

### D

door 的通风圆口、深色门楣和窗框把门亭接进后方奶油色房屋；props 的山崖、松林、灯塔在石地和矮墙之外。close 的秤有独立木撑，鱼箱靠近砧板，网收在侧墙。近处深绿木板的斑驳纹较重，秤后壁架与吊索重合，棚顶与后墙间还能看见一条三角形天光。

**首轮到终图**　first 的高亮门灯和支架挡住门牌左部；final 的 door 把灯收在左柱旁，鱼徽和站名得以完整露出。props 的暖灰山景转为分层蓝灰岩岸，远处出现条纹灯塔。close 的厚黄台边变薄，蓝绿台架与木面分开，台沿增加条纹布。构造更清楚，右侧吊盘里的内容在终图阴影中较难辨认。

### E

door 门柱的刻度尺、左侧救生圈与起吊垂环给入口一个岸边用途；props 的木地延续到台前，卧桶坐在短托脚上。close 能把挂鱼、鱼种图、砧板和地上排水格栅联系起来。网、浮标和双桨挤在同一片暗角，近景地板的几条深缝比台腿还醒目。

**首轮到终图**　first 的门灯和台灯泛成白团，网、盘绳和鱼背也接近白色；final 可见灯罩与护框，亮网退成暗绳。door 后墙添了小屋门窗和吊臂，props 与 close 增加挂鱼、布巾、台下箱和排水格栅。工作位置因此更好认，代价是右角渔具的轮廓有些并在一起，木地板拼口更突兀。

### F

door 以暗红顶和褐色粗框围住简洁的门名，props 的桶箍、板条箱和桌脚都有轮廓。close 的鱼牌比桌上的鱼更容易认；鱼身各三角面明暗跳变，深色小刀与暗砧板的明度接近。右墙留白较多，岸边装卸的空间线索偏弱。

**首轮到终图**　first 的空暗窗在 final 出现窗格，door 增加山墙鱼牌、柱号与箱体边条；props 左墙挂起四枚红、墨绿与米白相间的浮标，close 增加台秤，站号移到灯右边。秤和浮标补足了用途，灯不再压住站号文字，却与新鱼牌的右部重叠；门外大箱的正面仍接近整块暗色。

## 可见约束与证据边界

- 共同白盒 door 已有青色门形、右中与右前的橙色体块以及左缘测试块，props 右缘已有矮块。终图门右的箱体会遮去工作台下部，这些位置有白盒来源。比较看各家如何包覆它们，以及剩余视野里的入口和台面能否辨认。
- 六组 door 均能透过门柱之间看到后方地面；props 可见石铺或板铺干地。C、D 的门前另铺短木板，C 的 props 有一道深色横条从台脚延到木铺前缘，E 的 close 在排水格栅旁有几处明显的暗缝与板端错口。这些接缝在固定机位可见，实际高差和脚下通行情况仍待实测。
- 近景有明确的投影重叠。A 的招牌盖过后窗上部，D 的壁架穿过吊秤索的画面轮廓，E 的网、浮标和桨柄在右墙叠合，F 的灯遮到鱼牌右缘。D 的 close 还有一条从屋面与墙顶之间露出的天空；截图只支持记录这些视线或收口问题。

缺少正式版同高度、可环看的门洞及岸上切配台参考。参考 02 按原像素尺寸在内存转码显示，候选两轮均按三机位原图查看。静帧无法量验门洞净宽 1.2 米、净高 2.3 米、制作范围、地面高差、坡道／台阶／跳台的完整保留、碰撞和实际可走性，也无法核验素材来源或授权。本次偏好限于这六组，仍与原作在大色面取舍和空间自然衔接上有距离。尚未获用户验收。
