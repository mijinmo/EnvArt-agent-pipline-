# D1 双风机检修间

在 Godot 4.7.2 Forward+ 打开此目录。scenes/start.tscn 是冻结起点，scenes/pass01.tscn 是第一次制作。evidence 中的整体、检修台和入口图片来自同一组三个相机。

## 首轮制作

主参考 51 的钢架比墙面暗，连续洋红导线横穿蓝绿墙片，光集中在设备下方。辅助图 60 的大型旋转设备有分段涂装、内凹的深色机械接缝，前景钢板有长圆冲孔。起始场景的两块方板和静直的细叶片难以表达检修风机的厚度，门框和地砖也缺少区分材质的面变化。

本轮保留工程内 Quaternius 的原始素材和两份 CC0 许可。以 Prop_Fan_Small_service 原始顶点、索引和局部半径改造风叶，制作截面递进的铸壳、法兰螺栓和双路供管；备用叶轮采用同一个改造网格。椅、油桶、工台、立式开关台保留原始网格分区，按表面用途重新赋色。利用 Platform_3Plates、WallAstra 和 WallBand 的原始网格加上金属冲孔、钢板拼缝和墙面分色。重画总牌、切断开关面板、监测屏及手部安全图示。门上联锁锁壳和工台下抽屉是补充件。components 中的 OBJ 可在模型工具中编辑；场景内的 MeshInstance3D 可独立移动，材质参数可在 Inspector 中修改。

press_enamel 用 UV 横坐标索引十六色样，通过世界法线选取明面、背光面和高光面，阴面随模型坐标生成斜线，ink_load 控制其深浅。stamped_deck 在原始钢板 UV 底色上用世界坐标绘制冲孔、唇边、缝和通道漆线。liner 的 tram 控制洋红色服务带覆盖度。原屏幕描边缩至 1.24 像素，停用屏幕排线。此处同时改变了几何和材质，没有单独测量 shader 的贡献。

首轮已保存、重开并用共享包装脚本在 Metal Forward+ 实际捕获三图，GPU 队列等待 0.0 秒。图中厚环、紧固件和分色已经可读；冲孔板太亮、连续平行漆线抢眼，检修叶轮内部仍空，小道具细节也弱。入口左右罩壳缺少识别特征。下一轮只针对本组图像修订。

环境记录：系统 Python 未安装 PIL，改用已安装的 bundled Python。两次 headless 编辑器导入写入了本地导入缓存，沙箱拒绝保存全局编辑器首选项及快照目录；未影响场景加载和出图。首轮图形捕获一次成功。仓库共同输入准备情况见上级 BRIEF.md。
