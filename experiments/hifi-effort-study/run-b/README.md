# D1 双叶轮检修间

使用 Godot 4.7.2 Forward+ 打开本目录的 project.godot。scenes/start.tscn 为冻结场景，scenes/pass01.tscn 为第一轮。三组固定机位在 Views 下。第一轮捕获一次，输出三张 1600×1000 图像，GPU 排队 0 秒。

51.jpg 的走道以深蓝结构压住墙板，用红色局部照明和跨板色带划区，地板防滑孔比细划痕更醒目。60.jpg 的大机器以亮红主体、黄色切线、凹口和层叠截面表达重量。起图的双风机装在方板上，两台运转状态相似。全景里地面细小金属反光与近景检修器件争夺注意力。

第一轮保留 Quaternius 的风机、工作台、设备、门楣、墙和地板网格。资产为共同输入里的 CC0 免费模型，许可保存在 art 目录。原创铸造侧颊、带密封层的外圈、进风槽和底部散热盒沿现有叶轮装配。B 机增加有转轴、栓帽和斜纹的隔离杆，与桌边的 HOLD 状态对应。制作了原创旋转机械安全插画和车间横幅。几何增件保存在 fabrication，可独立移动。

第一轮的 press_ink.gdshader 读取真实材质的底色图，以 enamel、shade、stock_mix、hatch_density 和 surface_role 调整色墨、阴影、原贴图占比、排线与钢板冲孔。applied_finishes.gd 在场景加载时逐表面绑定，编辑器中也能预览。start 的屏幕轮廓参数沿用。首轮回看，地板槽、墙板折边和检修器件压线被抹得过平，工作台下方和门框外缘仍是大片空色。导入及捕获成功。沙箱内 headless editor 报个人设置目录不可写，产物导入完成，图形捕获日志无报错。共同起点缺少的 painted_whitebox 由试验组织者统一补齐。

## 最终场景与看图记录

打开 scenes/final.tscn，按 F6 可运行当前场景。art/SweptImpeller* 在 Quaternius 免费风机的原顶点、骨架和材质槽上重塑叶片，尖端按半径后掠，更新法线并保留动画数据。A 机应用青绿色和黄铜色，B 机采用橙色叶片和象牙色内圈，插入隔离杆的端部挂有挂牌。黄色连杆工作灯和带抽屉的工具柜安装在原检修台上。

最终材质保留首轮网孔和排线，读取原资产切线空间法线图，以正负坡度分别绘制浅压线和暗凹槽；地坪、箱盖和工作台零件的形状在近景重新可辨。两处检修指示的青红色足迹直接写在地板材质上，随世界坐标落地。它们是美术绘制的光斑。press_ink_final.gdshader 的 stock_mix 控制底图权重，hatch_density 控制每米排线数量，use_normal 控制模压细节；final_finishes.gd 依源网格和单表面原贴图选择金属、涂漆和墙面色料。屏幕描线沿用冻结场景。

实际执行两轮制作、两次 GPU 图形捕获，每次均重开场景并输出 overall、detail、transition，共六张 1600×1000 原图。两轮 GPU 排队均为 0 秒，渲染均成功，无重拍、无启动或 shader 故障。两轮各进行一次 headless 素材导入，随后另一次仅为 final 证据 PNG 生成 .import 文件；沙箱阻止个人编辑器设置写入，均未阻塞工程素材导入。环境探查发现系统 Python 没有 Pillow，制图实际使用已安装的 bundled Python。对比三个相机节点及 ProtectedWhitebox 引用逐字相同，白盒源场景含 17 个 StaticBody3D。

全景能区分运行与锁定工位，桌下柜体及工作灯在 detail 视角更清楚。地坪压线和安全告示在近景仍有抢眼的地方，墙右侧和过门外仍是大片简单体面，后掠叶片在远景显得较细。项目本轮未做玩法和运动验收，三张最终图是固定相机下的视觉结果。

交付整合：F5 默认打开 scenes/final.tscn；冻结起点仍可打开 scenes/start.tscn 后按 F6 查看。整合只改默认入口，不改已审阅场景和截图。
