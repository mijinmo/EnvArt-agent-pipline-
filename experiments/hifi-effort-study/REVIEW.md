# Hi-Fi Rush effort 对照的评图范围

四组对照的是从同一既有局部继续改善漫画风格的能力，不是从零建场，也不是找新素材的测试。两张原作参考、资产访问范围、白盒、固定相机与两轮额度相同。

评图先比较最终实机，再结合源码说明原因；不能只按实现了多少 shader 特性评分。主要观察：

- 漫画式体面与材质：明暗组织、表面图形、磨损与线条的层次，是否仍像 PBR 模型套描边。
- 模型与细节统一：主要设备轮廓、比例、支撑关系，以及旁边桌椅箱桶是否使用同一种视觉语言。
- 光影与可读性：主次、投影、空间深度，以及风格化是否压没了必要细节。
- 同局部完整性：整体、近景、门洞均成立，保留白盒和镜头约束。

在质量可接受的候选里比较原始墙钟耗时和实际 token 记录。缓存输入、非缓存输入和输出分别列出，reasoning 是输出的组成部分，不重复相加。没有本次订阅的逐任务扣费，因此不能把 total_tokens 当成金额。单次试跑存在随机性；结论只适用于这批内容与此次工作额度。

父 agent 制作期间不提供分组美术反馈。参考之外的方法由各 agent 自行选择。首批三组共同缺失依赖已补齐；后启动的 medium 没有这段准备等待，耗时比较需保留这一限制。

另由独立视觉评审 agent 先看参考和共同起图，再看四组全部终图；不提供 effort 映射、用量、实现说明或父 agent 的排序。它只作视觉判断，父 agent 最后结合资源记录；这仅减少评审预期偏差，不构成多次重复实验。评审开销单列为组织开销，不计入任何生产组。

## 完成后的独立视觉结论

独立评审未获得各组 effort 或用量，逐一看完四组三机位后给出 C > A > D > B；C/A 接近，A/D 差距不大，D/B 差距较清楚。它指出如果只看风机特写，D 会排第一。对应模型参数在评价形成之后由父 agent 映射：C=xhigh、A=high、D=medium、B=low。

- C：大块浅地板与深靛顶梁托出红橙设备；近景叶片折面、网点、机械臂关节与椅壳排线相互呼应，入口控制盒和地面导线延续同一视觉语言。右墙/浅柜偏平亮，机械臂遮住海报。
- A：墙灯点阵光锥最贴近参考 51；机壳分面、吊臂深度、终端与抽屉共同组织工位。地板槽纹重复偏密，叶片更像直板，入口双列文字抢眼。
- D：弯叶叠压、浅叶尖与蜂窝网清楚表现转子厚度，门柱外壳也有体量。周边管道和箱体仍有细碎金属高光，终端柱/桶则偏平，整体材质未与风机统一。
- B：齿口安全海报和检修锁杆有识别度，确有局部造型改变；但针状扇叶、密集浮雕地坪、黑白品牌屏仍显混杂，入口深灰矩形遮住操作说明。相比起点，图形设计的贡献占比较高。

四组共同仍是并排贴墙的双风机，缺少参考 60 中大型设备、机械臂和通道在纵深上交错的构图。本次固定白盒及局部范围限制了这种布局改造。主 agent 的逐图判断与上述综合排序一致；用户美术验收尚未给出。

## 资源结合后的取舍

在达到整块局部的风格统一这一目标下，父 agent 暂选 high。它比 medium 多约 1.9 分钟和 15.9% 输出 token，较完整地处理了周边；xhigh 比 high 多约 34.5% 墙钟时间与 37.9% 输出 token，视觉领先较小。缓存输入/未缓存输入也有增长，不能把这些比例称为费用比例。

low 是成本最小的提案候选，high 是本次质量与耗时的折中；若更重视最终近景的一致性，可接受 xhigh 的额外工作量。此结论没有证明“high 永远最佳”，也没有验证 max/ultra 或其他场景任务。只比较了四个独立单次样本，没有增加第二轮模型复测。
