# D1 双风机检修间 · run-c

在 Godot 4.7.2 Forward+ 打开本目录的 project.godot。冻结输入在 scenes/start.tscn，第一轮在 scenes/pass01.tscn。evidence 中的 overall、detail、transition 分别是设备间全景、工作台近景与入口。截图均为 Godot Metal 实机输出，1600 × 1000。

## 第一轮

对照共同主图 51，深蓝梁连接板压在低饱和墙面上，墙带跨过接缝，红色灯区在边缘露出印刷网点。辅助图 60 的大机器靠有厚度的分段壳、黄色警示漆、深色密封和轴销分面。冻结起点里的主要问题是方形装饰板承托一圈窄叶片、工位设备沿用同一种反光、地板起伏密且看不出受力与区域，入口平面护板遮住编号。设计围绕风机、备件、锁定操作三者展开。

- 从现有 Quaternius 免费版 Modular Sci-Fi MegaKit 和 Sci-Fi Essentials Kit 的模型继续。包内许可证位于 art，两者为 CC0。仅使用本地实际模型。模型与贴图未另行下载。
- 保留风机进口、支承圈、六叶轮毂与叶根的原始拓扑。在休止姿态的静态派生模型上，扩宽并后掠六个叶尖，将进口径、轴座、卷唇重新定比例。加折面切角壳、四个锁紧座和螺栓，A 机装护网，B 机裸露。工作台夹具处放置同一规格拆出的叶轮。
- 墙边补两路弯管、法兰和阀轮。入口门柱换成带折边、拨杆、散热片的锁具壳。原桁架接点补铆接板，工作台、椅子、箱、柜、结构管沿用原网格。单件模型与各材质覆盖均可在 models 目录打开。
- 新绘甲板印版、设备铭牌、门楣、工位门头与手掌／转子安全海报。大面采用按朝向分段的珐琅色、饰面角色对应的材质及世界坐标排线。两只检修灯的网点落在相邻设备和甲板，原屏幕轮廓降到 1.2 像素。shaders/enamel_print.gdshader 的 surface_role 切换甲板、墙、上部梁及设备，trim_ink 是原 UV 饰面保留量，hatch_strength 是排线强度，local_light 和 graphic_light 分别控制灯光和示警灯图形的贡献。
- 第一轮实机三图能辨出两台设备的状态、拆件与安全海报。全景中地板和前景箱仍近似整块填色。近景终端和工作台正面细节不足，门锁排线几乎均匀覆盖整个黄色面。第二轮选这三处修订。

技术记录：制作一轮，重新打开后一次捕获三机位，共三张；共享 GPU 等待 0.0 秒。导入中 Godot 把名字结尾为 wheel 的阀轮识别为车辆节点，加载检查发现一条覆盖失效警告，改名后再导入。图形捕获零次失败。沙箱内 headless 编辑器打印了用户设置目录/证书访问告警，导入的工程资源已在已保存场景中加载。工具探测发现系统 Python 无 Pillow，改用已有的本机打包 Python。
