# Godot 环境美术 Agent 管线基础

更新日期：2026 年 11 月 12 日。

本项目面向业余时间有限的关卡设计师：输入关卡白盒、设计约束和美术要求，由 agent 优先寻找可商用素材，必要时通过 Blender 适配或制作，再在 Godot 中装配成可玩的环境。玩家控制器和白盒工具是支撑环境美术产出的基础设施。

## 目标与范围

第一阶段要跑通一个小型场景的完整流程：白盒读取 → 设计意图识别 → 资产选择 → 适配与制作 → Godot 装配 → 视觉与玩法复查 → 局部迭代。

兼容性通过明确的数据约定、配置和可替换模块获得。当前不建设完整游戏框架，也不以将练习白盒迁移到正式项目为主要目标。通用组件可以在其他项目复用，但不为此提前扩展任务、背包、战斗或存档系统。

## 基础能力

| 能力 | 最小约定 | 用途 |
| --- | --- | --- |
| 白盒输入 | 1 单位为 1 米、Y 向上、局部前方为负 Z；给出场景范围与物体用途 | 统一尺寸并区分墙体、掩体、建筑占位等含义 |
| 设计保护 | 锁定位置、碰撞、通路净空、跳跃落点、关键视线；明确允许改变的内容 | 限制美术装饰对玩法的影响 |
| 美术目标 | 参考图、风格、镜头距离、目标平台、性能预算 | 决定资产筛选和制作精度 |
| 资产规则 | 来源、许可证、尺度、风格、质量、处理成本和性能 | 形成可解释的取舍 |
| 场景装配 | 目录、资源引用、材质、碰撞归属、生成内容身份 | 支持稳定导入与局部更新 |
| 观察验收 | 玩家视角、自由观察、固定机位、通行及视线检查 | 对比装饰前后的视觉与玩法 |

## 白盒语义与设计约束

几何形状不足以表达关卡意图。一个长方体可能表示实体墙、掩体、建筑占位或遮挡视线区域。关键内容由设计师标记，其他内容可由 agent 提出推断；不确定且影响玩法的推断需要先澄清。

约束示例：墙体位置和碰撞保持不变；可替换材质、添加表面装饰；门洞有效宽度不得缩小；指定观察点到目标的视线必须保留。标记提供意图，实际结果仍需要碰撞检查与试玩。

场景应区分白盒几何、玩法碰撞、设计标记与美术表现。初期几何和碰撞可由同一组件生成，但美术替换必须能独立保留玩法碰撞。树木、栏杆等影响通行或视线的资产要明确记录其玩法作用。

## 资产获取与制作顺序

1. 先搜索已有项目资产和本地资产库，再搜索在线来源。
2. 对候选记录原始链接、作者、许可名称与证据、下载或核实日期、署名及再分发要求。免费不等于可商用；许可不明的资产不进入正式产物。
3. 按轮廓与尺度、风格、材质、性能、文件可用性和适配成本筛选。不能因为素材漂亮就自动改变受保护的关卡尺寸。
4. 合适素材直接使用；可通过轻量改动满足要求时优先适配。
5. 缺少合适候选或适配成本过高时，再通过 Blender 自建或程序化生成。

这是一套起始决策规则。具体资产站点、质量阈值、预算和许可证白名单将在首个完整场景中落实；当前不假设全网素材都可自动下载或再分发。

## 模块边界

- 角色运动只处理身体尺度、速度、跳跃和碰撞，接受世界空间移动指令。
- 相机负责视角、跟随、第三人称避障和自由观察，不决定关卡玩法。
- 输入适配器将键鼠操作转换成运动与相机指令，可替换为回放、自动巡检或其他输入。
- 试玩环境连接各模块，处理出生、跌落复位与调试界面。
- 资产来源、建模方式和白盒输入各自通过接入层转换为一致记录，暂不提前实现多个来源。
- 未来轨迹相机由相机管理层协调，不让角色运动依赖某个插件。

默认避免隐藏的全局依赖。配置明确提供单位、碰撞层、输入动作和资源路径；不通过固定的外部节点路径寻找玩家或全局管理器。

## 局部更新与内容归属

生成美术需要对应到稳定的区域或源物体身份，并区分原始白盒、生成内容、人工修改与已确认保留内容。重新运行时应能预览替换范围、保留锁定物体并清理本次范围内的旧生成物，避免重复堆叠或覆盖人工工作。

首个控制器阶段只建立独立测试环境；上述语义、资产追踪和局部生成系统尚未实现。

## 观察与验收

基础验收包括尺度与通行、坡面与跳跃、关键视线、相机遮挡、美术一致性以及目标设备性能。截图只能证明某个机位的外观，不能代替实际通行和运行性能验证。

未来的固定机位与轨迹应保存位置、方向、FOV、时间或路径位置，便于在白盒和美术版本之间重复采样。玩家配置独立于具体控制器，以便切换第一人称、第三人称或其他观看方式。

## 实施顺序与当前交付

1. 已实现基础角色移动、第一人称、第三人称、自由观察和独立控制器测试场；操作与边界见 [控制器说明](player-controller.md)。
2. 已实现原生 Path3D、PathFollow3D 与 AnimationPlayer 轨迹相机，支持时间定位、播放暂停与四种视角切换，见 [HTML 图文教程](rail-camera-guide.html)。原始方案比较保留在 [轨迹相机研究](camera-path-research.md)；没有安装第三方相机插件。
3. 下一阶段选择一小段代表白盒，确定美术目标、保护规则和平台预算。
4. 跑通一次素材检索、适配、装配与验收，再据真实问题扩展自动化。
